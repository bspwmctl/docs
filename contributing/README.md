# Contributing to bspwmctl

Thank you for your interest in contributing! 🎉

## Quick Links

- [Main Contributing Guide](https://github.com/bspwmctl/bspwmctl/blob/main/CONTRIBUTING.md) - Full guidelines
- [Code of Conduct](https://github.com/bspwmctl/bspwmctl/blob/main/CODE_OF_CONDUCT.md) - Be respectful
- [Issues](https://github.com/bspwmctl/bspwmctl/issues) - Report bugs or request features

## Ways to Contribute

### 🐛 Report Bugs

Found a bug? [Open a bug report](https://github.com/bspwmctl/bspwmctl/issues/new?labels=bug&template=bug_report.md).

### 💡 Suggest Features

Have an idea? [Request a feature](https://github.com/bspwmctl/bspwmctl/issues/new?labels=enhancement&template=feature_request.md).

### 📖 Improve Documentation

Documentation can always be better! Feel free to:

- Fix typos or unclear instructions
- Add examples or screenshots
- Write new guides

Submit PRs to the [docs repository](https://github.com/bspwmctl/docs).

### 💻 Contribute Code

Ready to code? Check out:

1. [Good first issues](https://github.com/bspwmctl/bspwmctl/labels/good%20first%20issue)
2. Read the [Contributing Guide](https://github.com/bspwmctl/bspwmctl/blob/main/CONTRIBUTING.md)
3. Fork, code, and open a PR!

### 🎨 Share Themes

Created a cool theme? We'd love to see it! *(theme repository coming soon)*

## Development Setup

```bash
# Fork and clone
git clone https://github.com/YOUR_USERNAME/bspwmctl.git
cd bspwmctl

# Create a branch
git checkout -b feature/your-feature-name

# Make your changes
# ...

# Test your changes
./bspwmctl check

# Commit and push
git add .
git commit -m "feat: add awesome feature"
git push origin feature/your-feature-name
```

Then open a pull request on GitHub!

## Code Style

- Use 4 spaces for indentation (not tabs)
- Keep lines under 100 characters when possible
- Add comments for complex logic
- Follow existing code patterns

## Getting Help

Need help contributing?

- Comment on the issue you're working on
- Ask questions in your PR
- [Open a question issue](https://github.com/bspwmctl/bspwmctl/issues/new?labels=question&template=question.md)

## Thank You! ❤️

Every contribution, no matter how small, helps make bspwmctl better for everyone.
