# bspwmctl Documentation

Welcome to the official documentation for **bspwmctl** - an automated installer and manager for bspwm desktop environments.

## What is bspwmctl?

bspwmctl helps you install, configure, and manage bspwm desktop environments without the headaches. It supports multiple Linux distributions and comes with pre-configured dotfiles ready to use.

## Features

- 🐧 **Multi-distribution support**: Works on Debian, Ubuntu, Arch, Manjaro, Fedora and derivatives
- 📦 **Multiple installation modes**: Choose between minimal, standard, or full setups
- 🎨 **Pre-configured dotfiles**: bspwm, sxhkd, kitty, polybar, picom and more
- 🔧 **Automated setup**: Compile and install all components automatically
- 🚀 **Simple CLI**: Easy to use command-line interface

## Quick Start

```bash
# Clone the repository
git clone https://github.com/bspwmctl/bspwmctl.git
cd bspwmctl

# Make executable
chmod +x bspwmctl

# Install (minimal mode - default)
./bspwmctl install

# Or install standard mode
./bspwmctl install --standard
```
